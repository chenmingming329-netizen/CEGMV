# Install Guide

## 1. 下载插件文件夹

将完整插件文件夹下载到本地，例如：

```text
browser_agent_extension_v15_creative_dashboard_score
```

## 2. 加载 Chrome 扩展

1. 打开 Chrome
2. 访问：`chrome://extensions/`
3. 打开右上角「开发者模式」
4. 点击「加载已解压的扩展程序」
5. 选择插件文件夹

## 3. 启动本地管家

双击：

```text
kill_8774_then_start.bat
```

成功后会看到：

```text
本地管家已启动：http://127.0.0.1:8774
```

## 4. 打开素材 Dashboard

```text
http://127.0.0.1:8774/creative-dashboard
```

## 5. 注意事项

- 不要上传 `snapshots/` 目录
- 不要上传 TikTok Cookie / Token / API Key
- 不要公开真实广告数据
